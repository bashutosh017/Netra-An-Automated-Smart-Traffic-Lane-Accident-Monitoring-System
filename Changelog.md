# Changelog

All notable changes to Netra are recorded here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to follow [Semantic Versioning](https://semver.org/) once releases begin.

## How to Use This File

- Add every user-visible change under **Unreleased** as you work.
- When you publish a version, rename **Unreleased** to the version number and date, then start a fresh **Unreleased** section.
- Group entries under these headings: **Added**, **Changed**, **Deprecated**, **Removed**, **Fixed**, **Security**.
- Write for people, not machines. Say what changed and why it matters.

## [Unreleased]

### Added
